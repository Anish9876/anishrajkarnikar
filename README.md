# Anish Rajkarnikar – Portfolio

Static site (plain HTML/CSS/JS, no build step).

- `index.html` – main portfolio
- `machan-county-villa.html` – case study

Before going live: in `index.html` find `var TO="your-email@example.com";` and put your real email.

## Deploy with GitHub Pages
1. Create a repo and push these files to the `main` branch.
2. Repo → Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)` → Save.
3. Your site goes live at `https://<username>.github.io/<repo>/`.

Netlify / Vercel / Cloudflare Pages also work: connect the repo, leave build command empty, publish directory `/`.
